The Omnes Hashprice Index

Our own measure of what one petahash per second of hashrate earns in a day. It is computed in the page from public Bitcoin network data, refreshed every minute: the block subsidy and the average fees per block over the last 144 blocks, which is one day at the target block time; the network hashrate estimated by mempool.space over the last 1,008 blocks, about seven days; and the Bitcoin price from mempool.space. It is an estimate for information only.

Current value per note is an indicative calculation. It assumes today's Omnes Hashprice Index level holds for the rest of the term, which it will not, it is before any Costs or tax liabilities still to be paid, and it is not a price at which notes can be bought or sold. Returns are not guaranteed, and investors can lose some or all of their investment.
