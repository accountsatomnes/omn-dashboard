How the figures are calculatedPer note
Current value
Bitcoin per note × Bitcoin price, plus days left in term × current hashprice × 1 PH/s
Bitcoin per note
(Mined, gross of pool fees, plus any Bitcoin paid in its place) ÷ notes outstanding
Term
18 months, 548 days counting the first and last day
Current hashprice
144 × (block subsidy + average fees per block, last 144 blocks) ÷ network hashrate in PH/s × Bitcoin price, in USD per PH/s per day. The network hashrate is mempool.space's estimate over the last 1,008 blocks, about seven days. It is an estimate for information only.

Current value per note is an indicative calculation. It assumes today's hashprice holds for the rest of the term, which it will not; it is before any costs or tax liabilities still to be paid; and it is not a price at which notes can be bought or sold.
